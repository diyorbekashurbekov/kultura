# 🎭 Культурный отдых: Интеллектуальный Турнир Трёх Групп (Практическое занятие №6)

Интерактивный образовательный веб-портал, созданный специально для проведения командного занятия в студенческой аудитории и защиты перед руководством / ректором.

🌐 **Онлайн-версия (GitHub Pages)**: [https://diyorbekashurbekov.github.io/kultura/](https://diyorbekashurbekov.github.io/kultura/)

---

## 👥 Структура трёх групп занятия:
1. 👑 **Группа «Презентующие» (6 человек — ведущие)**: 
   - Авторы проекта и хозяева сцены. Защищают теоретический базис, раскрывают компетенции РОД1–РОД5, управляют интерактивной доской, модерируют соревнование и присуждают баллы. В состязании за очки не участвуют.
2. 🔵 **Команда «Дополняющие» (5 человек — участники турнира)**: 
   - Боевая команда №1. Отвечает на вопросы викторины, дополняет теорию, соревнуется на скорость в угадывании шедевров и дебатах.
3. 🟣 **Команда «Оценивающие» (6 человек — участники турнира)**: 
   - Боевая команда №2. Проводит критический анализ, состязается в знании терминов, отстаивает аргументы в дебатах и борется за кубок занятия.

## 🌟 Содержание и архитектура портала:
- **📜 Поэзия и цитаты о силе искусства (Вводный блок)**:
  - Стихи Николая Заболоцкого («Не позволяй душе лениться!») и А.С. Пушкина («Театр уж полон...»).
  - Мудрые цитаты К.С. Станиславского, П.И. Чайковского, Л.Н. Толстого.
- **⚔️ Турнирная арена (Интерактивное табло очков Live Scoreboard)**:
  - Прямой подсчёт баллов: Команда «Дополняющие» vs Команда «Оценивающие».
  - Модераторская панель Презентующей группы (`+1`, `+2`, `+3` балла).
  - Церемония награждения победителей с салютом и конфетти (Canvas Confetti).
- **🎮 5 Соревновательных раундов**:
  - Раунд 1: Блиц-дуэль (15 вопросов с пояснениями).
  - Раунд 2: Арт-битва (Шедевры живописи и архитектуры на скорость).
  - Раунд 3: Эстафета терминов (Культурный классификатор: Театр, Музей, Музыка, Литература).
  - Раунд 4: Лексический дуэль (Обобщающее слово — Задание 1 УМК).
  - Раунд 5: Финал — Дебаты спикеров с таймером выступления (1 минута).
- **📚 Академический блок**: УМК, компетенции РОД1–РОД5, научные факты роли искусства.
